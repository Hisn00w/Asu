# ASu 更新日志

## [0.0.3] - 2026-08-13

### 改进

- 启动界面支持显示 ASu 像素 Logo，并针对窄终端自动限制显示宽度。
- 更新检查改为读取 npm 上的 `@hisn00w/asu-agent`，不再显示其他项目的版本信息。
- 启动帮助、认证提示和求职相关交互继续使用中文。

### 修复

- 移除上游项目遗留的版本更新提示和无关更新日志。
- 移除 `/login` 帮助中的英文参数占位符。

## [0.0.2] - 2026-08-13

### 改进

- 完善中文求职系统提示词、简历酥化、简历制作和秋招进度管理能力。
- 优化 ASu Agent 的终端标题、启动界面和 npm 发布配置。

## [0.0.1] - 2026-08-13

### 初始版本

- 提供 `/asu`、`/resume` 和 `/offer` 三个中文求职技能入口。
- 支持通过 npm 全局安装并使用 `asu` 命令启动。
- 基于上游可扩展 agent 框架完成 ASu Agent 定制。
